# piagrid-data

Public, read-only market data for piagrid.com calculators (electricity tariffs, taxes, limits, market prices, exchange rates).

- `values.json` is generated by the n8n workflow "PG - Market Data" from the Airtable base "Piagrid Market Data" (published values only). Do not edit it by hand.
- Every value carries its unit, validity period, official source and the date the source was read.
- Served at https://onurtekinturhan.github.io/piagrid-data/values.json
